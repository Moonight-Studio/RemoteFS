# RemoteFS 隐私政策

更新日期：2026-09-16

## 应用收集的数据

RemoteFS 应用不向开发者收集、出售或共享个人数据，不包含广告、分析、追踪或崩溃上报 SDK。文件名、服务器地址、凭据和浏览历史不发送给开发者。

## 设备上的数据

连接配置（包括服务器地址、用户名和路径）、偏好设置、历史记录、媒体索引与缩略图保存在设备本地。密码保存在系统凭据存储中，Apple 平台使用钥匙串，不明文写入连接配置。支持私钥认证的版本将口令存入系统凭据存储；Mac App Store 版本不提供私钥文件认证。

预览和播放可能生成应用本地缓存，与主动下载分开。可在设置中管理缓存大小和清理缓存。删除连接可移除相关保存凭据；移除连接不等于安全擦除所有缓存。试用到期不会删除本地数据，缓存管理仍可用。

## 网络访问

应用直接连接用户配置或选择的服务器，以读取目录、生成缩略图、预览、播放、下载或执行用户发起的写入操作。文件流量不经过开发者服务器。SFTP 使用 SSH；HTTPS WebDAV 使用 TLS；普通 FTP 不加密。

## Apple 试用与购买

支持试用和永久解锁的 Apple 版本使用 StoreKit。Apple 处理付款与购买历史，应用在设备上验证签名购买记录，以决定使用权限和恢复购买。开发者不接收银行卡信息，也不在服务器保存购买记录。钥匙串中的本地时间记录用于防止通过修改时钟重置试用。七天试用结束不会自动扣费或变成订阅。

## 网站与支持反馈

本站由 GitHub Pages 托管。GitHub 为安全目的记录访客 IP 地址，具体见 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。本站没有额外的分析脚本、广告、Cookie 或第三方脚本。

你主动提交的 GitHub Issue、用户名和反馈内容对外公开，并用于回复与处理问题。不要在公开反馈中提供密码、密钥、私人服务器详情或私人文件。

## 联系方式

隐私问题与支持请求可通过 [RemoteFS 支持入口](https://github.com/Moonight-Studio/RemoteFS/issues) 提交。请仅提供脱敏后的必要信息。
